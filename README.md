# Telecom Site Health Check Operational Dashboard

## Overview

This project is an end-to-end Power BI analytics solution designed to monitor and analyze operational site validation activities after network deployment.

The dashboard transforms large Excel-based operational tracking data into an interactive reporting platform that enables users to monitor validation outcomes, investigate operational issues, analyze KPI exceptions, and review site-level performance through a centralized dashboard.

---

## Business Problem

Operational teams often maintain site validation records in spreadsheets containing deployment status, audit results, alarm information, KPI evaluations, and operational health indicators.

As the number of sites increases, manually reviewing thousands of records becomes difficult and time-consuming.

Key challenges included:

* Tracking site validation status across multiple regions
* Identifying failed sites requiring investigation
* Monitoring alarm-related operational issues
* Reviewing audit compliance results
* Analyzing KPI validation failures
* Performing operational reporting using large Excel trackers

The lack of centralized reporting reduced visibility into operational performance and increased manual analysis effort.

## Solution

Developed an interactive Power BI dashboard to centralize operational monitoring and validation reporting.

The solution provides:

* Executive operational summary
* Site validation monitoring
* Operational issue investigation
* KPI validation analysis
* Detailed record-level reporting

The dashboard enables users to quickly identify operational exceptions, investigate failed validations, and analyze site health metrics through dynamic filtering and drill-down capabilities.

---

## Dashboard Features

### Executive Cutover Summary

Provides a high-level overview of operational performance.

Key Metrics:

* Total Sites
* Pass Sites
* Failed Sites
* Alarm Sites
* Full Cutover Sites
* Partial Cutover Sites
* Missing RAN ID Sites

Insights:

* Regional performance comparison
* Weekday vs Weekend activity analysis
* Site deployment distribution
* Validation outcome monitoring

---

### Site Health Check Tracking

Monitors operational health indicators after site deployment.

Includes:

* Cell synchronization analysis
* Enabled vs Disabled cell monitoring
* Locked vs Unlocked cell tracking
* Alarm occurrence monitoring
* Audit failure analysis
* Operational site health reporting

---

### Failed Site Investigation

Dedicated investigation page for operational exceptions.

Capabilities:

* Analyze failed validations
* Review alarm details
* Investigate audit failures
* Examine operational health indicators
* Filter and drill down to site-level records

---

### KPI Validation Matrix

Monitors KPI evaluation results across multiple technology layers.

Features:

* KPI Pass/Fail matrix
* Conditional formatting
* Technology-wise KPI validation review
* Exception identification and analysis

---

### Detailed Operational Tracker

Provides complete record-level visibility into operational data.

Includes:

* Site information
* Region
* Validation status
* Alarm details
* Synchronization status
* Lock/Unlock status
* Audit outcomes
* Operational health indicators
